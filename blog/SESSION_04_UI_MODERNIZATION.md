# 4편: 미적 집착과 에이전트의 정교함 - 진정한 "바이브코딩"의 탄생

강력한 엔진과 시스템 통합이 완료된 `unim`에게 남은 과제는 '아름다움'이었습니다. 리눅스 앱은 투박하다는 편견을 깨고 싶었던 저의 욕심, 그리고 그 욕심을 현실로 만들어준 **Gemini 3 Flash**와 **Antigravity(에이전트 모드)**의 환상적인 콜라보레이션이 시작되었습니다.

```text
c8a0427 | 2026-01-28 | style(settings): GTK4/Qt6 Adwaita 다크 테마 UI 개선
```

## Gemini 3 Flash와 Antigravity: 바이브에 날개를 달다

이 시점부터 개발의 문법이 완전히 바뀌었습니다. 이전까지의 AI 개발이 "내가 시키는 일을 AI가 대신 해주는 것"이었다면, **Gemini 3 Flash**의 압도적인 추론 속도와 **Antigravity**라는 에이전트의 실행력이 결합되면서 저는 비로소 **진정한 '바이브코딩'**의 경지에 진입하게 됩니다.

저는 더 이상 개별 코드 라인을 고민하지 않았습니다. 대신 에이전트에게 저의 '감각'과 '취향'을 던졌습니다.

> "Gemini, 지금 이 UI는 너무 기계적이야. Antigravity와 함께 좀 더 유기적이고 프리미엄한 느낌을 내줘. Adwaita의 정수는 살리되, 사용자에게 '와, 이건 다르다'라는 느낌을 주는 그런 다크 모드 말이야."

## 1픽셀의 타협도 허용하지 않는 페어 프로그래밍

Gemini 3 Flash는 제 의도를 빛의 속도로 파악했고, Antigravity는 그 의도를 즉시 실제 코드로 구현해냈습니다.

- **GTK4/Qt6의 심미적 통일**: 서로 다른 세계의 코드를 Gemini가 분석하고, Antigravity가 수천 줄의 스타일 시트를 수정하며 1픽셀의 오차도 없는 일관된 UI를 완성했습니다.
- **예술적 완성도**: 폰트의 두께, 아이콘의 여백, 마우스 호버(Hover) 시의 미세한 애니메이션까지. 혼자라면 "이쯤이면 됐지"라고 타협했을 디테일들을 에이전트와 함께 집요하게 파고들었습니다.

## 버튼을 없애고 "경험"을 심다: AI가 일궈낸 사용성

사용자가 무언가를 바꾸자마자 바로 적용되는 **'Instant-save'** 기능. 이 복잡한 DBus 연쇄 반응과 설정 동기화 아키텍처는 Gemini 3 Flash의 명석한 설계 능력이 없었다면 시작도 못 했을 일입니다.

에이전트는 단순히 코드를 짜는 것을 넘어, 제가 놓친 예외 상황들을 먼저 짚어주며 완벽한 사용자 경험을 설계했습니다. 덕분에 사용자는 '저장' 버튼을 누르는 수고를 덜고, 기술이 주는 매끄러운 경험만을 온전히 누릴 수 있게 되었습니다.

## 바이브코딩, 고행을 축제로 바꾸다

젓가락 타이핑을 하는 저에게 UI 코딩은 가장 고된 작업이었지만, 이제는 가장 즐거운 '유희'가 되었습니다. 제가 느낀 그 '바이브'가 Gemini와 Antigravity라는 붓을 통해 화면이라는 캔버스에 즉각적으로 그려지는 과정은 그 자체로 거대한 축제였습니다.

이제 `unim`은 단순히 돌아가는 프로그램이 아니라, 개발자의 영혼과 AI의 지능이 결합된 하나의 '작품'이 되었습니다.

## 4편을 마치며

이제 `unim`은 튼튼한 심장(Rust 엔진)과 아름다운 얼굴(Adwaita UI)을 모두 가졌습니다. 하지만 이 화려한 겉모습 뒤에는 시스템의 가장 밑바닥에서 벌어지는 치열한 통신 전쟁이 숨어 있었습니다.

다음 편에서는 에이전트의 분석력을 빌려, 윈도우 시스템의 보이지 않는 심부(DBus)와 고대의 유물(XIM)을 어떻게 현대적으로 정복했는지 그 눈물겨운 사투기를 들려드리겠습니다.
