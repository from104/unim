# 블로그 연재: '우연히 시작하게된 바이브코딩으로 만든 한글 입력기' (상세 목차)

커밋 로그 분석과 **AI 에이전트(Antigravity)와의 협업**이라는 특별한 경험을 중심으로 재구성한 목차입니다.

---

## [프롤로그] 우연히 시작하게 된 바이브코딩, 한글 입력기가 되다
- **Moment**: 젓가락 타이핑의 허탈감과 Rust의 고해성사.
- 사이버대학 시절 오토마타와 작년 여름의 실패, 그리고 가을의 반전.

## [1편] 자음과 모음의 춤: 한글 조합 엔진의 기초
- **Moment**: 2024-07-03 `Initial commit`
- Java 오토마타를 Rust로 포팅하며 겪은 10번 이상의 실패와 '임시' 커밋들의 사투.

## [2편] 이름의 변화와 성장의 진통: Unin에서 Unim으로
- **Moment**: 2025-04-23 `unin에서 unim로 이름 변경`
- 단순 전환 프로그램에서 '유니버설 입력기'로의 비전 확장.

## [3편] 신의 한 수: 에이전트 모드와 입력기의 대폭발
- **Moment**: 2026-01-11 `restructure project and move core logic to root crate`
- **핵심 내용**: 단순 그놈 확장 프로그램을 넘어, 시스템 전체를 아우르는 '진짜 입력기'로 도약하게 된 극적인 전환점. 
- **AI의 힘**: 혼자서는 엄두도 못 냈을 수백 개의 파일 수정과 아키텍처 변경을 가능하게 한 **에이전트 모드**의 등장.

## [4편] 미적 집착과 에이전트의 정교함: UI 현대화
- **Moment**: 2026-01-28 `GTK4/Qt6 Adwaita 다크 테마 UI 개선`
- 에이전트와 함께 GTK4, Qt6를 아우르는 일관된 럭셔리 UI를 구축한 과정.
- 'Instant-save' 등 고난도 UX 메커니즘을 에이전트와 페어 프로그래밍으로 해결한 기록.

## [5편] 시스템 심부로의 침투: DBus와 XIM의 벽을 넘다
- **Moment**: 2026-01-19 `migrate to DBus-based IPC architecture`
- 에이전트의 논리적 분석력을 빌려 복잡한 시스템 통신 프로토콜을 정복한 이야기.

## [6편] TypeFIX, 마침내 완성된 한글 솔루션
- **Moment**: 2026-01-14 `rebrand to UNIM TypeFIX`
- 입력 지연 제로, 오타 수정까지. 보편적 도구로서의 완성.

- 완벽하지 않은 인간 개발자와 완벽을 추구하는 에이전트가 만든 하모니.
- 앞으로의 로드맵과 회고.
