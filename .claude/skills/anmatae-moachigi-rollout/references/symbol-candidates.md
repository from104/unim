# 안마태 자판 — 고어 자모 위치 한글 조판 기호 대체 후보

> 본 파일은 Phase 3 산출물(`_workspace/anmatae/04_symbol_replacement.md`)의 표준 후보 풀이다. 매니저는 안마태 원본의 고어 자모 위치마다 본 후보 풀에서 3종 이상을 선정해 사용자에게 제시하고, 사용자 결정 1종만 `jamo_symbol_map`에 반영한다.

## 사용자 요구

- 한글 고어(아래아 ㆍ, 옛이응 ㅇ̇ 등)는 도입 제외
- 자리에는 **한글 조판에 쓰이는 기호** 대체
- 기호는 emit char로 즉시 commit (HangulComposer 큐 진입 금지)

| 안마태 원본 위치 | 원 자모 | 권장 대체 | 사유 |
|----------------|--------|-----------|------|
| 가운뎃점 자리 1 (lower) | `ㆍ` | `·` (U+00B7) | 시각적 동일, 한글 본문 가운뎃점 표준 |
| 가운뎃점 자리 2 (upper/shift) | `ㆍ` shift | `…` (U+2026) | 줄임표, 입력 빈도 매우 높음 |

## 사용자 결정 양식

매니저가 제출하는 `04_symbol_replacement.md`는 다음 양식을 따른다:

```markdown
## 고어 자모 위치 매핑 — 사용자 결정 요청

### 위치 1: <키 식별자 (예: 'p' lower)>
- 안마태 원본: ㆍ (U+318D)
- 후보 A: · (U+00B7) — 가운뎃점, 한글 본문 표준
- 후보 B: · (U+30FB) — 가타카나 가운뎃점, 한·일 혼용
- 후보 C: ◦ (U+25E6) — 흰 동그라미, 강조
- **매니저 권장**: A
- **사용자 선택**: [ ] A  [ ] B  [ ] C  [ ] 직접 입력: ___

### 위치 2: ...
```

사용자가 단일 선택 후 `jamo_symbol_map`에 반영. 미결정 위치는 안마태 자판 빌트인 등록 보류.

## 안전 규칙

- 옛한글 분류 코드포인트(U+302E/F, U+318D 등)는 사용자가 명시적으로 원할 때만 후보 채택
- 후보 간 시각적 혼동 가능성(`·` vs `・`)은 명시적 비교 컬럼 추가
- ASCII 기호(`*`, `^`, `~`)는 한글 조판 비표준이므로 후보에서 제외 (사용자 명시 요청 시 예외)
