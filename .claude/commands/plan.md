# UNIM Plan — 독립 기획 에이전트

작업을 분석하고 구현 계획을 수립한다. `/harness`의 Phase 1을 단독 실행할 때 사용.

## 사용법

```
/plan <작업 설명>
```

## 실행

Agent tool로 `subagent_type: "Plan"` 에이전트를 실행한다.

프롬프트:
```
UNIM 프로젝트(/home/from104/work/unim)에서 다음 작업을 기획하라:

작업: $ARGUMENTS

수행할 것:
1. 관련 소스 파일 탐색, 현재 상태 파악
2. CLAUDE.md 아키텍처 규칙 준수하는 계획 수립
3. 변경 대상 파일과 구체적 변경 내용 명시

출력:
- **목표**: 1줄
- **변경 파일**: file:line 형식
- **구현 순서**: 단계별
- **검증 방법**: 성공 기준
- **리스크**: 주의사항
```

계획 결과를 사용자에게 보여주고 피드백을 받는다.
