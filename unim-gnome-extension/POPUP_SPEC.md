# UNIM 팝업 기본 명세

## 핵심 동작

1. **팝업 위치**: 대상 글자 위로 표시 (글자를 가리지 않도록)
2. **preedit 유지**: 팝업이 열려 있는 동안 preedit(조합 문자)은 유지
3. **네비게이션**: preedit 유지한 채 팝업 내에서 후보 탐색 (화살표, PgUp/PgDn, 숫자키 등)
4. **선택**: 후보 선택 시 해당 한자/특수문자가 커밋되고 팝업 닫힘
5. **취소**: 아래 모든 경우에 preedit 값이 그대로 커밋되고 팝업은 닫힘
   - ESC 키 입력
   - 포커스 아웃 (창 포커스 상실)
   - 창 전환
   - 입력 필드 변경
   - 리셋 요청
   - 네비게이션 키 외의 키 입력

## 아키텍처 원칙

- **엔진 위임 모드**: 모든 키는 ProcessKeyEvent → Rust 엔진으로 전달. 엔진이 상태를 관리하고 DBus 시그널(ShowPopup, PopupNavigate, HidePopup)로 UI를 갱신
- **팝업은 순수 UI**: 키 처리 로직 없음. 렌더링과 마우스 이벤트 콜백만 담당
- **단일 상태 소스**: 엔진의 PopupState가 유일한 진실의 원천. `updateFromNavigate()`가 유일한 상태 업데이트 경로
- **마우스 인터랙션**: 클릭으로 선택, 호버로 시각적 하이라이트 (엔진 상태와 독립적인 로컬 시각 효과)
