# UNIM 로고 첫인상 분석

> 한글 입력기 **unim** 로고(`assets/unim-logo v2.svg`)에 대한 디자인 첫인상 정리.
> 핵심 컨텍스트: 리눅스·윈도우 크로스 플랫폼, **자동 한영 전환**을 핵심 기능으로 개발 중.

---

## 0. 실제 SVG 구조 (path 디코드)

512×512 캔버스, 둥근 사각형 프레임(`rx=115`, 약 22% — 슈퍼타원형 squircle).

핵심 그래픽은 **3개의 서브패스**로 구성된 단일 `<path>` (stroke-width `70` ≈ 캔버스의 14%, `linecap/linejoin=round`, 드롭섀도 `dy=12 / blur=16`):

| 구성 | 좌표 | 의미 |
|------|------|------|
| `u` 왼쪽 줄기 | x=106, y 117→320 | 짧은 왼쪽 기둥 |
| `u` 바닥 | arc r75, (106,320)→(256,320), 아래로 볼록 | 컵(▽) 형태 |
| **공유 줄기** | x=256, y 117→**395** | u의 오른쪽 = n의 왼쪽, **가장 긴 획** |
| `n` 아치 | arc r75, (256,192)→(406,192), 위로 볼록 | 역컵(△) 형태 |
| `n` 오른쪽 줄기 | x=406, y 192→395 | 오른쪽 기둥 |

**핵심 발견:** 기존 문서가 표현한 "끊김 없이 하나로 이어진 선"은 정확하지 않다. 실제로는 **중앙 수직 줄기(x=256)를 공유하며 융합된 u+n** 구조이며, u(아래로 볼록한 컵)와 n(위로 볼록한 아치)이 그 줄기를 축으로 **상하 거울 대칭**을 이룬다. 연속성은 단일 스트로크가 아니라 *공유 줄기에 의한 융합*에서 온다 — 오히려 이게 더 강한 디자인 서사다.

색상: 배경 `#380b14→#140206`(거의 검정에 가까운 와인), 획 그라데이션 `#ff3b53→#90001a`(좌상단 밝은 코랄 → 우하단 짙은 핏빛, 대각선 방향).

## 1. 디자인 요소별 첫인상

| 요소 | 인상 |
|------|------|
| 짙은 와인빛 배경 + 코랄→핏빛 대각 그라데이션 | 강렬함·열정·에너지·자신감. 시선을 한눈에 사로잡음 |
| 굵은(14%) 둥근 끝 획의 소문자 `un` | 묵직하면서도 부드러운 펜 터치, 세련된 현대미 |
| squircle 프레임 + 드롭섀도 | 구조적 안정감 + 살짝 떠 있는 입체감·전문성 |
| 공유 줄기로 융합된 모노그램 | 미니멀·직관, 그리고 '하나로 합쳐짐'의 명확한 서사 |

**종합:** 현대적이고 세련되면서도 강렬한 첫인상. 굵은 획과 round cap 덕분에 트레이/작업표시줄의 소형 아이콘에서도 형태가 또렷하게 살아남는다(실용적 장점).

---

## 2. '한글 입력기' 맥락에서의 해석

- **공유 줄기 = 융합의 축** — u와 n이 중앙 한 줄기를 공유 = 두 요소가 별개가 아니라 하나의 뿌리에서 갈라져 나옴. 한글의 초·중·종성이 한 글자로 모이는 '모아쓰기' 구조와 통한다.
- **컵(u)과 역컵(n)의 거울 대칭** — 위/아래로 반전되어 맞물린 형태 = 자음과 모음, 혹은 한/영 두 모드가 하나의 프레임 안에서 대칭으로 공존.
- **굵고 안정적인 획** — 가볍게만 보이지 않고, 시스템 전역에서 신뢰감 있게 동작하는 입력기라는 묵직함도 함께 전달.

### 이름 'unim'과의 조화
- 핵심 알파벳 `u`·`n`을 메인 그래픽으로 직관 시각화.
- 융합 구조 → **Unified / Universal** 가치 → 어떤 OS에서도 호환되는 입력기라는 신뢰감.

---

## 3. '자동 한영 전환' 기능과의 링크

- **하나의 줄기, 두 개의 모드** — 공유 줄기를 축으로 u·n이 대칭 = 한/영 키를 따로 누르지 않아도 문맥에 따라 한 축 위에서 자동으로 모드가 뒤집히는 '대칭 전환'.
- **컵↔역컵의 반전** — 위로 볼록(n) ↔ 아래로 볼록(u)의 180° 반전은 한영 전환의 '뒤집힘'을 기하학적으로 형상화하기에 최적. 애니메이션에서 줄기를 축으로 회전/반전시키면 전환을 직관적으로 전달 가능.

---

## 4. 크로스 플랫폼 관점

- **리눅스** — Fcitx·IBus 등 기능 중심의 딱딱한 입력기들 사이에서, GNOME·KDE에 설치 시 독보적으로 트렌디한 오픈소스/인디 SW 인상.
- **윈도우** — squircle 프레임·부드러운 그라데이션이 Windows 11 Fluent Design과 조화. 굵은 획 덕에 트레이/작업표시줄 소형 표시에서도 또렷.

---

## 5. 브랜딩·디자인 제언

- **공유 줄기 서사 강조** — 마케팅·웹사이트에서 "두 언어, 하나의 줄기" 같은 카피로 융합 구조를 전면화하면 자동 전환 정체성과 직결된다.
- **반전 애니메이션** — 중앙 줄기를 축으로 컵(u)↔아치(n)가 채워지거나 색이 교차하는 효과(한글 입력 중 vs 영어 입력 중 톤 변화)로 자동 전환을 시각화.
- **한글 획 미세 융합(선택)** — round cap이 이미 붓 터치 느낌을 주므로, 끝처리에 `ㄴ`·`ㅡ`의 기하 요소를 절제해 더하면 '한글' 정체성을 직접 각인 가능.

### 상태 표시 활용 아이디어
- squircle 미니멀 아이콘으로 변형(획이 굵어 축소에 강함).
- 입력 상태(한/영)에 따른 획 색상 반전·하이라이트, 또는 컵/아치 방향 토글.
