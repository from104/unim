# Legacy Java Implementation (docs/references/java)

이 프로젝트의 한글 조합 로직 및 오토마타 설계는 `docs/references/java` 디렉토리에 포함된 Java 소스 코드를 기반으로 하고 있습니다.
이 코드는 한글 입력기(IME)의 핵심 엔진을 구현하기 위한 설계 철학을 담고 있습니다.

## 주요 클래스 및 역할

### 1. `HangulJamo.java`

한글의 기본 구성 요소인 자모를 정의합니다.

- `Cho` (초성): ㄱ, ㄲ, ㄴ, ㄷ, ..., ㅎ (19개)
- `Jung` (중성): ㅏ, ㅐ, ㅑ, ㅒ, ..., ㅣ (21개)
- `Jong` (종성): (없음), ㄱ, ㄲ, ㄳ, ..., ㅎ (28개)
- 각 자모는 유니코드 순서(Sequence), 첫가끝 방식 유니코드, 호환용 유니코드 값을 가집니다.

### 2. `HangulChar.java`

한글 한 글자(음절)를 표현하고 변환하는 클래스입니다.

- **조합(Composition)**: 초성, 중성, 종성 값을 조합하여 하나의 완성형 음절 유니코드를 계산합니다.
  - 공식: `0xAC00 + (초성순서 * 21 * 28) + (중성순서 * 28) + 종성순서`
- **분해(Decomposition)**: 완성형 음절 코드를 다시 초성, 중성, 종성으로 분리합니다.

### 3. `HangulBuilder.java` (추상 클래스)

한글 오토마타의 상태 관리를 위한 추상 클래스입니다.

- `mJamoStack`: 입력된 자모를 순서대로 쌓아두는 스택입니다.
  이를 통해 Backspace 처리 시 직전 상태로 정확히 되돌아갈 수 있습니다.
- `combinedJamo`: 복합 자모(예: `ㄱ`+`ㄱ`=`ㄲ`, `ㅗ`+`ㅏ`=`ㅘ`, `ㄴ`+`ㅎ`=`ㄶ`)를 처리하기 위한 매핑 테이블을 관리합니다.

### 4. `HangulBuilder2Bul.java` 및 `HangulBuilder3Bul.java`

실제 입력 방식(2벌식, 3벌식)에 따른 조합 로직을 구현합니다.

- **도깨비불(Dokkaebibul) 현상 처리**: 2벌식 입력 시 종성이 입력된 상태에서 모음이 들어오면,
  종성을 다음 글자의 초성으로 이동시키는 로직이 구현되어 있습니다.
- **상태 전이**: 자모 스택의 상태를 분석하여 현재 글자에 포함될지, 다음 글자로 넘어갈지를 결정합니다.

## 설계 특징

1. **스택 기반 상태 관리**: 단순히 현재 글자만 기억하는 것이 아니라, 입력 스트림을 스택으로 관리하여
   복잡한 조합 및 삭제 시퀀스를 안정적으로 처리합니다.
2. **유니코드 표준 준수**: 현대 한글의 유니코드(U+AC00 ~ U+D7A3) 조합 규칙을 엄격히 따릅니다.
3. **확장성**: `HangulBuilder`를 상속받아 새로운 입력 방식(단모음, 세벌식 최종 등)을 쉽게 추가할 수 있는 구조입니다.

이 Java 코드는 현재 Rust로 재작성된 `src/korean` 폴더의 구조적 모태가 되었습니다.
