# UNIM (Windows) 사용 안내 — v0.3.54

## 1. UNIM이란?

**UNIM**은 Rust로 만든 오픈소스 한글 입력기입니다. Windows에서는 **TSF**(Text Services Framework) 방식으로 동작해 대부분의 앱(메모장·크롬·워드·터미널 등)에서 한글을 입력할 수 있고, **한자·이모지·특수문자 입력**과 **한/영 자동 오타 교정(AutoTypeFix)** 같은 편의 기능을 제공합니다.

설치는 `unim-0.3.54-x64.msi`를 실행하면 됩니다. 설치 후 **재부팅(또는 재로그인)** 하면 입력기 목록에 UNIM이 나타납니다.

> v0.3.54에서 새로 들어간 것: 화면낭독기(NVDA/Narrator) 대응, 팝업 다크/라이트·고대비 테마, 한/영 전환 소리 알림 등 **접근성 기능**.

## 2. 설정 창 여는 법

설정은 별도 창(**UNIM Settings**)으로 뜹니다. 세 가지 방법이 있습니다.

| 방법 | 순서 |
|------|------|
| **A. 트레이 인디케이터** (추천) | 작업표시줄 시계 옆의 한/영 표시(`한`/`A`)를 **마우스 오른쪽 버튼**으로 클릭 → 메뉴에서 **`설정`** |
| **B. 시작 메뉴** | 시작 메뉴 → **UNIM** 폴더 → **`UNIM Settings`** |
| **C. Windows 언어 설정** | 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 키보드에서 UNIM 옵션 진입 |

> ⚠️ **주의**: 트레이 인디케이터를 **왼쪽 클릭하면 한/영 전환**이 됩니다. 설정은 반드시 **오른쪽 클릭 → 설정**입니다.
> (직접 실행: `C:\Program Files\UNIM\unim-tsf-settings.exe`)

설정 창은 **일반 / 오타 교정 / 억제 단어 / 사용자 사전** 4개 탭으로 구성되고, **바꾸는 즉시 적용**됩니다(따로 저장 버튼 불필요).

## 3. 기본 사용법

| 기능 | 기본 키 / 방법 |
|------|----------------|
| **한/영 전환** | `한/영` 키 또는 **오른쪽 Alt** |
| **한자 변환** | 한글을 조합한 상태에서 `한자` 키 또는 **F9** → 한자 후보 팝업 |
| **특수문자** | 초성 하나(예 `ㅁ`)만 조합한 뒤 `한자`/`F9` → 특수문자 팝업 |
| **이모지** | 조합 중이 아닌 상태(idle)에서 `한자`/`F9` → 이모지 팝업 |
| **후보 선택** | 숫자키 `1`~`9` 직접 선택 · 방향키 이동 · `Enter` 확정 · `Esc` 취소 · **마우스 클릭**도 가능 |
| **현재 모드 확인** | 트레이 인디케이터 글자 — 한글이면 `한`, 영문이면 `A` |

- 이모지/한자 팝업 부가키: 카테고리 전환 `A`~`L`, 열 점프 `Q`~`O`, 북마크 토글 `Space`, 9×9↔간략 보기 토글 `.`(마침표)
- `한자` 키는 상황에 따라 **한자·특수문자·이모지** 세 용도로 자동 전환됩니다.

## 4. 한/영 자동 오타 교정 (AutoTypeFix) 활용

**한/영 전환을 깜빡하고 친 오타를 자동으로 바로잡는** 기능입니다. 기본으로 켜져 있습니다.

- **정방향(영 → 한)**: 한글을 치려다 영문 상태로 입력한 경우
  예) 영문 상태에서 `dkssud` → **`안녕`** 으로 교정
- **역방향(한 → 영)**: 영문을 치려다 한글 상태로 입력한 경우
  예) 한글 상태에서 `ㅗ디ㅣㅐ` → **`hello`** 로 교정

### 주요 설정 (오타 교정 탭)

| 항목 | 기본값 | 뜻 |
|------|:------:|----|
| 자동 오타 교정 사용 | 켜짐 | 전체 on/off (끄면 아래 항목 모두 무효) |
| 정방향 (영→한) / 역방향 (한→영) | 둘 다 켜짐 | 방향별로 따로 끌 수 있음 |
| 한글 음절 임계값 | 2 (2~6) | 이 **음절 수 이상** 모여야 교정 후보 (클수록 덜 교정) |
| 영문 단어 최소 길이 | 5 (3~8) | 이 **길이 이상** 영문 단어만 교정 (클수록 덜 교정) |
| 정/역방향 감지창(ms) | 5000 | 입력 후 이 시간 안에서만 판정 |
| 영어 단어는 교정 건너뛰기 | 켜짐 | 사전에 있는 진짜 영단어는 안 건드림 |
| 완성된 음절은 교정 건너뛰기 | 켜짐 | 이미 완성된 한글은 제외 |
| 되돌리기(롤백) 감지 | 켜짐 | 사용자가 교정을 되돌리면 **학습해서 다시 안 고침** |
| 임시 항목 만료(시간) | 4 (1~12) | 자동 학습된 억제가 유지되는 기간 |
| 관찰 타임아웃(초) | 10 (5~15) | 오탐 판정을 위해 관찰하는 시간 |
| 사용자 사전 사용 | 켜짐 | 등록 단어를 교정에 반영 |

## 5. 교정 오탐(원치 않는 교정) 해소법

원하지 않는데 자동으로 고쳐질 때, **위에서부터 순서대로** 시도하세요.

**① 그 자리에서 바로 학습시키기 (가장 간단)**
오교정된 글자를 **백스페이스로 전부 지우고 → 한/영 키로 모드 전환 → 같은 걸 10초 안에 다시 입력**하세요. UNIM이 이걸 "오탐"으로 보고 **자동으로 억제 목록(억제 단어)에 등록**합니다. 이후 같은 입력은 안 고쳐집니다. (되돌리기 감지가 켜져 있어야 함 — 기본 켜짐)

**② 억제를 오래 유지하기**
①로 학습된 억제는 기본 **4시간 뒤 사라집니다**. 오래 유지하려면:
- 설정에서 **임시 항목 만료**를 최대 **12시간**으로 올리거나,
- 파일 `%APPDATA%\unim\typefix-blacklist.yaml`에서 해당 항목의 `status`를 `confirmed`(영구)로 직접 수정.
  *(현재 GUI에는 "영구 확정" 버튼이 없어, 완전 영구화는 이 파일 편집이 필요합니다.)*

**③ 방향만 문제라면 그 방향을 끄기**
- 영문 칠 때 자꾸 한글로 바뀌면 → **정방향(영→한) 끄기**
- 한글 칠 때 자꾸 영문으로 바뀌면 → **역방향(한→영) 끄기**

**④ 전체적으로 덜 고치게 민감도 낮추기**
- **한글 음절 임계값**을 올리고(예 2→4), **영문 단어 최소 길이**를 올리면(예 5→7) 웬만해선 교정하지 않습니다.

**⑤ 특정 영단어가 자꾸 한글로 보존/오교정될 때 → 사용자 사전**
- 설정의 **사용자 사전** 탭에 그 영단어를 추가하면 역방향 교정에서 **영문으로 보존**됩니다.
- ⚠️ **영문 알파벳만** 등록 가능합니다(하이픈·숫자·한글·공백 불가). 예: `github` ✅ / `git-lfs`·`한글` ❌

**⑥ 억제 목록 관리**
- 설정의 **억제 단어** 탭에서 목록 확인·개별 삭제·전체 삭제가 됩니다.

**⑦ 아예 끄기**
- 오타 교정 탭에서 **자동 오타 교정 사용**을 끄면 기능 전체가 꺼집니다.

> 참고: 교정 전용 **되돌리기 단축키는 없습니다.** 백스페이스로 지우는 그 동작 자체가 ①의 학습 신호로 쓰입니다.

## 6. 참고

- 설정 파일 위치: **`%APPDATA%\unim\`** (`config.yaml`, `typefix-blacklist.yaml`, `typefix-userdict.yaml`) — 편집 시 약 2초 뒤 자동 반영됩니다.
- **MS Word 등 일부 앱은 "단어 단위"로 조합**됩니다(스마트 확정 단위, 기본값 `winword.exe`·`wmux.exe`). 다른 앱을 이 방식으로 쓰려면 설정의 **단어 모드 앱**에 실행 파일명을 추가하세요(Windows 전용).
- **접근성**: 한/영 전환 시 **소리 알림**(한글 높은음/영문 낮은음)은 기본 꺼짐이며, 설정에서 켤 수 있습니다.
