# 안마태 자판 (2003) 사용 가이드

> **UNIM v0.3.0+** 기준. 안마태 신부와 KAIST 김진형 교수가 2003년 발표한 세벌식 모아치기 자판.

---

## 개요

안마태 자판은 **세벌식** 계열 자판으로, 초성·중성·종성 영역이 키보드에 고정 배치된다. 일반 두벌식·세벌식과 달리 **모아치기**를 지원한다. 모아치기란 한 음절을 이루는 자모를 짧은 시간 안에 동시에(혹은 연속으로) 눌러 한꺼번에 처리하는 입력 방식이다.

- **설계자**: 안마태 신부 + KAIST 김진형 교수 (2003)
- **자판 유형**: 세벌식(3벌식), 4행 배열
- **특징**: cho(초성)/jung(중성)/jong(종성) 영역 고정, 양방향 자모 결합, 모아치기 옵션
- **빌트인 프로파일 이름**: `ko_3bul_anmatae`

> **옛한글(고어) 미지원**: 안마태 원본 자판의 옛한글 자모 위치(W·T·G·J·B·N upper)는 한글 조판 기호로 대체된다. 옛한글 입력은 v0.3.0에서 지원하지 않으며, 향후 별도 검토 예정이다.

## 키 배열

### 영역 구분

안마태 자판은 키를 4행으로 나누어 영역을 고정한다.

| 행 | 영역 | 내용 |
|----|------|------|
| 2행 (QWERTY `Q`~`]` 줄) | 초성(cho) + 중성(jung) | ㅁ ㅅ ㄴ ㄹ ㅎ + ㅕ ㅑ ㅡ ㅛ ㅠ |
| 3행 (QWERTY `A`~`'` 줄) | 초성(cho) + 중성(jung) | ㅂ ㅈ ㄷ ㄱ ㅇ + ㅓ ㅏ ㅣ ㅗ ㅜ |
| 4행 (QWERTY `Z`~`/` 줄) | 종성(jong) | ᆽ ᆮ ᆸ ᆨ ᆼ ᆺ ᆫ ᆷ ᆯ ᇂ |

> cho/jung 영역은 2·3행에 혼재하며, jong 영역은 4행 전용이다.

### Lower (Shift 없음)

```
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ ` │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │ 8 │ 9 │ 0 │ - │ = │ \ │  ← 1행(숫자/기호)
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┴───┘   │
│ ㅁ│ ㅅ│ ㄴ│ ㄹ│ ㅎ│ ㅕ│ ㅑ│ ㅡ│ ㅛ│ ㅠ│ [ │ ]          │  ← 2행(초/중)
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤            │
│ ㅂ│ ㅈ│ ㄷ│ ㄱ│ ㅇ│ ㅓ│ ㅏ│ ㅣ│ ㅗ│ ㅜ│ ' │            │  ← 3행(초/중)
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┴───┘            │
│ ᆽ│ ᆮ│ ᆸ│ ᆨ│ ᆼ│ ᆺ│ ᆫ│ ᆷ│ ᆯ│ ᇂ                       │  ← 4행(종성)
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
```

> 4행의 자모는 **종성 전용 코드포인트** (U+11A8계)다. 2·3행 초성(U+3131계)과 코드포인트가 다르지만 동일 자음 소리를 가리킨다. 같은 `ㄱ`처럼 보여도 행마다 내부 값이 다른 것이 정상이다.

### Upper (Shift + 해당 키)

```
┌───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┐
│ ~ │ ! │ @ │ # │ $ │ % │ ^ │ & │ * │ ( │ ) │ _ │ + │ | │  ← 1행
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┴───┘   │
│ ㅁ│ ' │ ㄴ│ ㄹ│ … │ ; │ '│ / │ [ │ ] │ { │ }          │  ← 2행
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┼───┤            │
│ ㅂ│ ㅈ│ ㄷ│ ㄱ│ " │ ㅓ│ · │ ㅣ│ ㅗ│ ㅜ│ " │            │  ← 3행
├───┼───┼───┼───┼───┼───┼───┼───┼───┼───┴───┘            │
│ ᆽ│ ᆮ│ ᆸ│ ᆨ│ " │ ' │ ᆫ│ ᆷ│ ᆯ│ ?                      │  ← 4행
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
```

#### 한글 조판 기호 6개 (Shift + 키)

안마태 원본에서 옛한글 자모가 있던 자리를 한글 조판 기호로 대체한다.

| 키 | Shift+키 입력 | 문자 | 코드포인트 | 용도 |
|----|-------------|------|-----------|------|
| W | Shift+W | `'` | U+2019 | 닫는 작은따옴표 |
| T | Shift+T | `…` | U+2026 | 줄임표 |
| G | Shift+G | `"` | U+201D | 닫는 큰따옴표 |
| J | Shift+J | `·` | U+00B7 | 가운뎃점 |
| B | Shift+B | `"` | U+201C | 여는 큰따옴표 |
| N | Shift+N | `'` | U+2018 | 여는 작은따옴표 |

## 자모 결합 규칙

안마태 자판은 복잡한 자모를 두 자모의 조합으로 입력한다.

### 초성 결합

| 첫째 자모 | 둘째 자모 | 결과 |
|---------|---------|------|
| ㄱ | ㄷ | ㄸ |
| ㄱ | ㅇ | ㄲ |
| ㄱ | ㅎ | ㅋ |
| ㄴ | ㅅ | ㅆ |
| ㄷ | ㅈ | ㅉ |
| ㄷ | ㅎ | ㅌ |
| ㅂ | ㅈ | ㅃ |
| ㅂ | ㅎ | ㅍ |
| ㅈ | ㅎ | ㅊ |

예: `ㄱ` + `ㅎ` → `ㅋ` (거센소리), `ㄱ` + `ㄷ` → `ㄸ` (된소리)

### 중성 결합

| 첫째 | 둘째 | 결과 |
|------|------|------|
| ㅏ | ㅣ | ㅐ |
| ㅓ | ㅣ | ㅔ |
| ㅗ | ㅏ | ㅘ |
| ㅗ | ㅣ | ㅚ |
| ㅜ | ㅓ | ㅝ |
| ㅜ | ㅣ | ㅟ |
| ㅡ | ㅣ | ㅢ |
| (외 8개) | | |

### 종성 결합 (겹받침, 순서 무관)

`bidirectional_combine` 옵션이 ON이면 `(ᆨ, ᆯ)`과 `(ᆯ, ᆨ)` 모두 `ᆰ`으로 인식한다.

| 결합 | 결과 |
|------|------|
| ᆨ + ᆼ | ᆩ |
| ᆨ + ᆯ | ᆰ |
| ᆨ + ᆺ | ᆪ |
| ᆫ + ᆽ | ᆬ |
| ᆫ + ᇂ | ᆭ |
| ᆯ + ᆷ | ᆱ |
| ᆯ + ᆸ | ᆲ |
| ᆯ + ᆺ | ᆳ |
| ᆸ + ᆺ | ᆹ |
| (외 11개) | |

## 모아치기 옵션

GTK 설정 다이얼로그 > 자판 선택 > 자판을 "안마태 자판 (2003)"으로 선택하면 **모아치기** 그룹이 자동으로 나타난다. 이 그룹은 `supports_moachigi=true`인 자판에서만 표시된다.

### 옵션 1 — 양방향 자모 결합 (Bidirectional Combine)

**기본값: ON**

초성·중성·종성 영역 내에서 자모 입력 순서에 관계없이 결합을 시도한다.

- **ON**: `(ᆯ, ᆨ)` 입력도 `(ᆨ, ᆯ)` 정방향과 동일하게 `ᆰ`(ㄺ)으로 결합한다. "닭"의 받침을 ᆯ → ᆨ 순서로 쳐도 올바르게 처리된다.
- **OFF**: combinations 파일에 정의된 정방향 순서만 인식한다. 옵션 2(동시 입력 시간)는 이 옵션이 ON일 때만 동작한다.

### 옵션 2 — 동시 입력 시간 (Chord Window, ms)

**기본값: 50ms** | 범위: 10~100ms | 0 = OFF

첫 자모 타건 후 설정 시간(ms) 이내에 들어온 자모 전체를 한 음절 단위로 묶어 처리한다.

#### 동작 원리 (단일 윈도우)

```
첫 타건 도착
    │
    ├─ 타이머 시작 (N ms, 단일 윈도우 — 매 키마다 초기화하지 않음)
    │
    ├─ 윈도우 안에 추가 키 도착 → chord buffer에 누적
    │
    └─ 윈도우 만료 (또는 다음 키 도착 시점 기준으로 만료 감지)
           ├─ buffer에 자모 1개 → 일반 풀어쓰기 처리
           └─ buffer에 자모 2개 이상 → 묶음 처리
                  (영역별 분류 → 양방향 결합 → 음절 commit)
```

윈도우 만료는 다음 중 하나로 trigger된다:
- 설정 시간 경과 후 idle 상태 (자동 flush)
- Space·Enter·Tab·Backspace 등 비자모 키 입력
- 한/영 전환
- 포커스 이동(FocusOut)
- Escape (chord 폐기, 미확정 자모 버림)
- MAX 8자모 도달 (즉시 flush)

**0으로 설정하면** chord 동작을 완전히 끄고 자모를 즉시 처리한다. 기존 세벌식과 동일한 동작이다.

> **이 옵션은 옵션 1(양방향 자모 결합)이 ON일 때만 동작한다.**

## GTK 설정 다이얼로그 사용법

1. 트레이 아이콘 클릭 → **설정(Settings)** 열기
2. **자판** 탭 > 한국어 자판 항목에서 **"안마태 자판 (2003)"** 선택
3. 자판 선택 즉시 **모아치기** 그룹이 아래에 나타난다
4. **양방향 자모 결합** 토글: 디폴트 ON — 특별한 이유 없으면 켜 둔다
5. **동시 입력 시간 (ms)** 슬라이더: 10~100ms 범위. 입력 속도가 빠르면 낮게(20~30ms), 느리면 높게(80~100ms) 조정한다. 0으로 내리면 chord 완전 OFF.

> 세벌식 390·391·쿼티형 등 다른 자판을 선택하면 모아치기 그룹이 자동으로 숨겨진다.

## 입력 시나리오 예시

### 정상 음절 입력 (chord OFF, 또는 영역 순서대로 입력)

| 입력 순서 | 결과 | 설명 |
|----------|------|------|
| ㄱ → ㅏ → ㅁ | 감 | cho→jung→jong 순서 |
| ᆸ → ᆺ | ᆹ (받침 ㅄ) | jong 결합 |

### 모아치기 동시 입력 (chord ON, 50ms 안)

| 입력 (50ms 이내 동시) | 결과 | 설명 |
|---------------------|------|------|
| ㄱ + ㅎ + ㅡ + ㅣ | 킈 | cho: ㄱ+ㅎ→ㅋ, jung: ㅡ+ㅣ→ㅢ |
| ᆨ + ᆯ | ᆰ | jong 겹받침 (순서 무관) |

### 음절 분리 (50ms 초과)

| 입력 | 결과 | 설명 |
|------|------|------|
| ㄱ + ㅡ → (50ms 만료) → ㅎ + ㅣ | 그히 | 윈도우 만료로 두 음절로 분리 |
| ㄱ + ㅜ → (50ms 만료) → ㅎ + ㅏ + ㄷ + ㅏ | 구하다 | "구하다" 정상 분리 |

### 한글 조판 기호 입력

| 키 입력 | 출력 | 용도 |
|--------|------|------|
| Shift+B | `"` | 여는 큰따옴표 |
| Shift+G | `"` | 닫는 큰따옴표 |
| Shift+N | `'` | 여는 작은따옴표 |
| Shift+W | `'` | 닫는 작은따옴표 |
| Shift+J | `·` | 가운뎃점 |
| Shift+T | `…` | 줄임표 |

## 트러블슈팅

### "구하다"를 치면 "쿠ㅏ다"처럼 엉킨다

chord 윈도우 안에 `ㄱ`과 `ㅎ`이 함께 잡혀 `ㅋ`로 결합된 것이다. 두 가지 방법으로 해결한다.

- **방법 1**: 동시 입력 시간(chord_window_ms)을 더 낮추거나 0으로 끈다. "ㄱ"과 "ㅎ"이 다른 음절임을 시간으로 구분한다.
- **방법 2**: chord를 유지한다면 `ㄱ`을 타건한 뒤 윈도우(50ms)가 확실히 지난 다음 `ㅎ`을 친다. 의식적으로 음절 경계에서 잠깐 쉰다.

### 화면에 입력이 잠시 안 보인다 (chord 진행 중)

chord 윈도우가 만료되기 전까지 preedit(미확정 입력) 표시가 없다. 짧은 윈도우(50ms)라 거의 느끼기 어렵지만, 슬라이더를 100ms 이상으로 올리면 인지될 수 있다. 정상 동작이다.

### 자판을 바꿨는데 모아치기 그룹이 여전히 보인다

설정 다이얼로그를 닫고 다시 열면 반영된다. 또는 UNIM 데몬을 재시작한다.

### Escape 키를 눌렀더니 입력 중이던 자모가 사라진다

chord 진행 중 Escape는 buffer를 폐기(discard)한다. 미확정 자모 전체가 버려지는 것이 의도된 동작이다. 취소가 아닌 확정이 필요하면 Space나 Enter를 누른다.

## 제한 및 비목표

| 항목 | 상태 | 비고 |
|------|------|------|
| 옛한글(고어) 입력 | **미지원** | 옛한글 코드포인트 감지 시 `LoadError::ArchaicJamoNotSupported`로 거부. v0.4.0 이후 별도 검토. |
| preedit 진행 중 chord 시각화 | **미지원** | chord 만료 전까지 화면 무반응. 50ms 윈도우라 실사용 영향 미미. |
| 신세벌식M 등 변종 | **미지원** | 빌트인은 안마태(2003) 표준안만 포함. 변종은 사용자 자판 JSON으로 직접 제공 가능. |
| chord 최대 자모 수 | 8개 | 8자모 도달 시 즉시 flush. |
